Musical-content audit
- 40 exercises
- 10 original PLAY. songs/etudes
- 5,440 note/rest events
- 50 unique IDs
- 0 audit errors

Checks applied
- Each non-rest event is a single guitar note.
- TAB string + fret must equal the stored MIDI pitch exactly.
- Frets must be within 0–17.
- Fingering values, when present, must be 1–4.
- Durations must be one of: 1/16, 1/8, 1/4, 1/2, whole.
- Scale/arpeggio/song material with a declared pitch-class set is checked against it.
- Songs in this build are PLAY. originals only; no remembered/commercial transcription is used.

Important
This validates pitch, TAB, fingering range, rhythm values and tonal membership. It does not claim that every fingering is the only possible fingering; it is the fingering encoded for the exercise.
