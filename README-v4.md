# PLAY. Guitar Practice PWA v4

Diese Version verlagert den Schwerpunkt von textbasiertem Lernen auf selbstständiges Üben mit TAB, Metronom und Fortschritt.

Die Practice-Bibliothek enthält 696 eigene Übungen in Warm-up, String Skipping, Alternate Picking, Scales, Scale Sequences, Pentatonic, Arpeggios, Legato, Chord Changes, Rhythm, Fingerstyle, Speed sowie Stil-Drills für Blues, Rock, Metal, Country, Pop/Indie, Jazz, Funk und Reggae.

Jede Bibliotheksübung besitzt TAB, Start-BPM, Ziel, Schwierigkeit, Favoritenfunktion, individuelles Arbeitstempo und eine Bewertung, die das nächste Tempo beeinflusst. Die Bibliothek ist such- und filterbar und bleibt offline verfügbar.
