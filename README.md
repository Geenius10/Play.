# PLAY. Guitar Teacher – PWA v3

PLAY. ist eine installierbare, offline-fähige Gitarren-Lern-PWA. Version 3 verschiebt den Schwerpunkt von einer Practice-Sammlung zu einem geführten digitalen Gitarrenlehrer.

## Didaktisches System
Jede der 134 Lern-/Practice-Einheiten läuft durch fünf Phasen: **Verstehen → Sehen/Hören → Nachmachen → Fehlerhilfe → Test**. Die Foundation-Lektionen sind besonders ausführlich von Hand ausgearbeitet. Spätere Inhalte verwenden skill-spezifische Lehrlogik und die individuellen Ziele/Erfolgskriterien der jeweiligen Lektion.

Enthalten sind unter anderem interaktive Gitarren-/Saitenorientierung, anklickbare Saitentöne, Akkorddiagramme, TAB, Rhythmusdarstellungen, Arbeits-BPM/Metronom, Akkord-Arpeggio zum Anhören, Schritt-für-Schritt-Checks, Fehlerdiagnosen und ein verpflichtender Selbsttest vor dem Abschluss.

## Umfang
- 134 Lektionen/Übungen in Foundation, Beginner, Intermediate, Advanced und Mastery
- 12 eigene lizenzfreie Practice-Songs
- Akkordbibliothek, Skalen-/Fretboard-System
- Tuner, Metronom, Tempo Trainer, Chord Changes, Ear Trainer, Timer und Jam Mode
- adaptive Sessions, Reviews, Mastery, History, Backup/Restore
- iPhone/iPad/Desktop responsive, Safe Areas, Offline-PWA

## Nutzung
Für Mikrofon/Tuner und reguläre PWA-Installation über HTTPS hosten. Auf iPhone/iPad in Safari öffnen und über „Zum Home-Bildschirm“ installieren.
